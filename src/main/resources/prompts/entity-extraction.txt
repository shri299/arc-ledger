Extract named entities, explicit facts, explicit state changes, and useful relationships. Mark direct text evidence as FACT,
semantic conclusions as INFERENCE, and unresolved claims as UNKNOWN. Use CHANGE only when the prose explicitly describes
a transition; otherwise use ASSERTION. Never invent a fact absent from the scene. Every proper name in the scene must be
considered as an entity; do not return an empty entities array when a named character, place, object, or organization is present.
